组件库

在你的项目里使用

  1. 安装（装一次，所有项目都能用）。在终端运行：
    Claude Code：claude plugin marketplace add KeelingYU/design-pal && claude plugin install design-pal@design-pal
    Codex：codex plugin marketplace add KeelingYU/design-pal && codex plugin add design-pal@design-pal
  2. 在项目里对 Agent 说：用 design-pal 给这个项目推荐组件库和颜色主题。Agent 说明理由，你同意后记录在项目中。
  3. 之后只说功能需求，不用再描述风格。
  4. 需要时可以说：「换成极客青」（换颜色主题）、「这个项目的按钮改成直角」（项目定制，只影响本项目）、「升级组件库」（先看改动说明，和你的定制冲突的地方逐条让你选）。
  5. 随时说「查看 design-pal 组件库」打开本页。
